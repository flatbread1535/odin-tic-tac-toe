Odin-Tic-Tac-Toe

This project uses HTML, CSS, and JavaScript to create a simple Tic-Tac-Toe webpage. This project was created for the Odin Project with the purpose of practicing skills with JavaScript factory functions and IIFEs. 

This project contains:
- A Tic-Tac-Toe board
- A button to reset the game board
- Two input fields for players to input their username
- Score tabs that track how many times a player has won

Concepts used for this project:
- Factory functions
- IIFEs
- HTML/CSS concepts from previous projects
